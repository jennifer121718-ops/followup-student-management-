# Followup — 物販スクールの生徒管理

通常のエックスサーバーに配置できる **PHP＋SQLite** の専用Webシステムです。講師は全員を管理し、生徒はログイン後、自分の情報だけを閲覧・入力します。PHP 8.1以上とPDO SQLiteが必要です。Composer、Node.js、常駐プロセスは本番運用に不要です。

## 使える機能

- 講師：月別ダッシュボード、提出状況、売上・純利益・売上前月比・目標達成率・ステータス、生徒検索・絞り込み。
- 生徒カルテ：基本情報、過去の月報、売上・粗利益・純利益のグラフと履歴、目標、相談事項、講師コメント。
- 生徒：本人の月報入力、下書き保存・提出・再提出、本人の履歴・目標・講師コメント閲覧。
- 在籍管理：生徒追加、基本情報編集、卒業・復帰、講師による生徒パスワード再設定。
- 運用：パスワード変更、月別CSV保存、講師専用の全データバックアップ。

生徒名、都道府県、参加期、開始日、売上、粗利益、純利益、販売個数、今月・来月の金額目標と文章の目標、振り返り、課題、行動、相談事項、講師コメント、3種類のステータスを管理します。

実名や実績は登録していません。実際の14名を講師画面から登録してください。人数は固定ではありません。

## エックスサーバーへの設置

[配置手順](XSERVER_SETUP.md)を参照してください。`dist/followup-xserver.zip` はWebプログラム、非公開フォルダ用ファイル、初回登録キー、手順書を含みます。実際の生徒データや共通パスワードは含みません。ZIPと初期設定キーは共有・公開しないでください。

配布ZIPを再生成する場合：

```bash
python3 tools/package.py
```

生成ごとに別の初期設定キーになります。新規設置用です。運用開始後の更新では、非公開データフォルダや初回キーを上書きせず、公開フォルダのプログラムだけを更新してください。

## ローカル起動

PHP 8.1以上とPDO SQLiteをインストールした端末で：

```bash
php -S 127.0.0.1:8000 -t web router.php
```

WindowsではPHPをPATHに登録後、`start.bat` でも起動できます。この端末のポート8000をブラウザで開くと、初回のみ講師アカウント作成画面が表示されます。ローカル版はループバックからのアクセスだけを想定しています。公開時はPHPの開発サーバーを使用せず、エックスサーバーのApache/PHPとSSLを使用します。

## 毎月の運用

1. 講師が14名の本人専用メールアドレスと基本情報を登録する。
2. 初期パスワードを個別に安全に伝え、本人に変更を依頼する。
3. 生徒が月報を下書き保存・提出する。提出後も再編集できます。
4. 講師が未提出者・要確認・フォロー必要で絞り込み、カルテでコメントを書く。
5. 卒業者は卒業扱いにしてログインを停止する。履歴は保持され、復帰も可能です。

目標達成率＝売上÷目標売上×100、前月比＝（今月売上−前月売上）÷前月売上×100です。前月未提出・前月売上0円は比較なし、目標0円は達成率なしと表示します。翌月の未入力月報には前月の来月目標を引き継ぎます。ダッシュボードの合計は在籍者の提出済み月報だけを集計します。粗利益・純利益は生徒が入力します。赤字も保存・表示できます。

## 閲覧権限とデータ保存

- サーバーがログイン利用者と生徒IDを照合します。他人のIDを指定してもデータの取得・変更を拒否します。
- 生徒一覧、基本情報の管理、講師コメント・ステータス変更、全データバックアップは講師だけに許可します。
- パスワードはSHA-256で固定長にしてから個別salt付きのPHP password_hashで保存し、bcryptの長さ切り捨てを防ぎます。
- セッションCookieはHttpOnly・SameSite=Strict。本番HTTPSではSecure必須、有効期限8時間です。DBにはセッションの原文トークンを保存しません。
- 更新にはCSRFトークンが必要です。異なるOriginの更新を拒否し、20回のログイン失敗で該当アカウントの再試行を15分制限します。
- 卒業・パスワード再設定でセッションを削除します。復帰しても古いログインは復活しません。
- 公開時の初回登録には配布パッケージの専用キーが必要です。登録後は初回登録を閉じます。
- SQLiteは公開フォルダの外に保存します。公開フォルダ内を指定すると起動を拒否します。

講師画面のバックアップを定期的に保存してください。バックアップには個人情報とパスワードハッシュが含まれます。生徒への共有、Gitへの追加、公開フォルダへの配置はしないでください。

## 検証

PHPを使った実HTTPテスト：

```bash
python3 -m unittest discover -s tests -p test_http.py -v
```

ブラウザテストは開発者向けです。PlaywrightとChromiumを用意して：

```bash
python3 tests/browser_smoke.py
node --check web/app.js
```

テストは一時フォルダの架空データだけを使用します。14名登録、月報提出、目標引き継ぎ、グラフ、コメント、バックアップ、権限分離、CSRF、卒業、パスワード再設定、初回登録キーを検証します。`PHP_BIN`でPHP実行ファイルを指定できます。
